# Runbook — nouvelle page publique

> Relu : 2026-08-13

1. Créer `views/front-pages/MaPage.vue` (coquille + `.front-wraper`).
2. Créer `components/frontpages/<feature>/` pour le contenu.
3. Styles dans `scss/frontpages/<feature>/`.
4. Route dans `router/FrontPagesRoutes.ts`.
5. Lien dans `Navigation.vue` / `Footer.vue` si besoin.
6. Vérifier squelette : AnnounceBar → Header → contenu → ContactBar → Footer.
7. `npm run validate`.
